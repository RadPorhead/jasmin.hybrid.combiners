# X-Wing in Jasmin

This repository contains the work related to **X-Wing** that was developed as part of my Master thesis: 

**"High-Assurance Implementation of CuKEM and Quantum Cryptanalysis of Its Underlying Primitives"**

## Based on

This work is based on the X-Wing implementation provided by the [X-Wing-KEM-Team](https://github.com/X-Wing-KEM-Team/xwing-benchmarks).

The project also relies on components from [Libjade](https://github.com/formosa-crypto/libjade).

## Branches

The `main` branch contains the modifications developed as part of my thesis. 

The `original_xwing_kem_team` preserves the original X-Wing implementation used as the starting point for this work.
